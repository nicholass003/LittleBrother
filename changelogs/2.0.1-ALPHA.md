# v2.0.1-ALPHA

**Released: 25 May 2026**

For PocketMine-MP API 5.43.x (Minecraft: Bedrock Edition)

This release focuses on improving protocol translation stability, packet serialization consistency, and internal compatibility handling for upcoming multi-version support architecture.

> [!WARNING]
> This is still an experimental alpha release. Protocol translation behavior may change frequently while the Axiom-based compatibility layer continues development.

---

## Added

* Added `AddActorTranslationHandler` support for entity metadata translation
* Added runtime ID translation handling for `EntityIds::FALLING_BLOCK`
* Added metadata variant conversion support during `AddActorPacket` translation

---

## Changed

* Improved packet translation consistency across protocol layers
* Updated internal runtime ID translation flow for block-related entity metadata
* Adjusted translation handling logic to reduce invalid runtime mapping behavior
* Improved internal protocol processing flow to align with ongoing Axiom architecture migration

---

## Fixed

* Fixed incorrect runtime ID handling for falling block entities
* Fixed invalid block variant metadata translation during `AddActorPacket` conversion

---

## Removed

* Removed obsolete temporary translation handling paths
* Removed unused compatibility logic from previous experimental implementations

---

## Internal

Internal changes that do not directly affect users but may impact development or architecture.

* Runtime mapping restructuring
