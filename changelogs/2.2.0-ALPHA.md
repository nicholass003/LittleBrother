# v2.2.0-ALPHA

**Released: 7 July 2026**

For PocketMine-MP API 5.44.x (Minecraft: Bedrock Edition)

This alpha release officially bumps the supported Bedrock protocol to v1001 (Minecraft: Bedrock Edition v1.26.30), adds level sound ID mappings, and refines client data upgrading for editor capabilities.

> [!WARNING]
> This is an experimental alpha release. Protocol translation behavior and internal mapping may change significantly as development continues.

---

## Added

- **Level Sound ID Mapping** – Added `resources/data/bedrock/level_sound_id_map.json` and registry loading via Axiom's `LevelSoundTypeRegistry` on enable.
- **`BedrockDataManager::getDataPath()`** – Added a public getter to retrieve the data path.

---

## Changed

- **Dependency Upgrades** – Axiom has been upgraded to version `~1.0.3`.
- **Client Data Upgrades** – Replaced legacy `IsEditorMode` upgrade with `ClientEditorConnectionIntent` and `ClientIsEditorCapable` options for better compatibility with protocol v1001.

---

## Fixed

- **LevelChunkPacket debug spam** – Skipped verbose debugging logs for `LevelChunkPacket` in `PacketTranslator` to improve console readability.

---

## Removed

- None.

---

## Internal

- Updated dependencies for improved stabilization of protocol v1001.
- Sound registry integration via Axiom during plugin enabling.
