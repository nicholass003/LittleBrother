# v2.0.0-ALPHA

**Released: 25 May 2026**

For PocketMine-MP API 5.43.x (Minecraft: Bedrock Edition)

This release introduces a major architectural transition from the legacy schema-driven translation system to the new **Axiom runtime translation architecture**.

The previous packet translation pipeline has been fully redesigned around runtime codecs and dynamic protocol handling, significantly reducing complexity while providing a more scalable foundation for future multi-version support.

This release also introduces protocol support improvements up to **Bedrock protocol v975**, alongside extensive cleanup of deprecated translation infrastructure and runtime mapping logic.

> [!WARNING]
> This is an **alpha release**. The new runtime translation architecture is still under active development and may contain incomplete packet handling, desync issues, or protocol compatibility regressions.

---

## Added

* Introduced the new **Axiom runtime codec architecture**
* Added support for newer Bedrock protocol versions up to **v975**
* Added bidirectional runtime ID translation support
* Added safer fallback handling for missing runtime mappings
* Added unified runtime translation handling across supported protocols

---

## Changed

* Replaced the legacy schema-driven translation pipeline with runtime-based codecs
* Reworked packet serialization and deserialization flow
* Simplified protocol translation handling across versions
* Refactored runtime block and item mapping systems
* Reduced protocol-specific translation complexity
* Improved maintainability of the multi-version translation layer

---

## Fixed

* Fixed several runtime translation inconsistencies between protocol versions
* Improved handling of runtime ID remapping failures

---

## Removed

* Removed legacy schema compiler infrastructure
* Removed generated schema dependency system
* Removed deprecated translation layers and unused compatibility paths
* Removed obsolete debugging and experimental translation logic

---

## Internal

* Major refactor of the core protocol translation architecture
* Integrated LittleBrother with the internal **Axiom** runtime system
* Reduced overall codebase complexity and translation duplication
* Improved separation between runtime codecs and protocol handlers
* Simplified future protocol upgrade workflow
